VALUE — HOW CASH VALUE IS ASSIGNED TO AMULETS                     built 2026-09-02
Primary data: data/analysis/value_factors.json (factors, tiers, chart_ready).

THE ANSWER
    Genuine-or-fake first; then the NAME (monk / temple / model); then issue
    and year; then mould and mintage; then metal tier; then condition.
    Blessedness is priced through the blesser's name, never through the rite.
    Bullion, frame, ceremony size and region of origin do not set price.
